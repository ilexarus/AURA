# AURA 0.6.1

Голосовой ассистент для Windows с локальной активацией по слову «Аура», визуальным конструктором команд, записью действий, голосовыми ответами и автоматическими обновлениями.

## Что исправлено в 0.6.1

- Кнопка проверки отдельного шага снова выполняет действие.
- Для проверки используются актуальные данные из модели редактора.
- Голосовая активация временно приостанавливается на время проверки шага.
- Пустое значение шага сразу показывает понятную ошибку.
- Новые версии проверяются через 5 секунд после запуска и затем каждые 15 минут.
- Старые настройки с интервалом в часах продолжают работать.

## Запуск исходников

1. Распакуйте проект в обычную папку, например `C:\AURA`.
2. Запустите `START_AURA.cmd`.
3. При первом запуске дождитесь установки компонентов.
4. Для полной переустановки окружения используйте `RESET_AND_START.cmd`.

## Основные возможности

- голосовая активация по слову «Аура»;
- запуск команд кнопкой и сочетанием клавиш;
- несколько действий в одной команде;
- запись мыши и клавиатуры;
- проверка отдельного шага и всего сценария;
- перемещение, дублирование и отключение шагов;
- поиск команд;
- локальные голосовые ответы;
- автоматическое обновление через GitHub Releases;
- аварийная остановка через `Ctrl + Shift + F12`.

## Пользовательские данные

Команды и настройки сохраняются отдельно от программы:

`%APPDATA%\AURA`

Обновление приложения не должно удалять пользовательские команды.

## Сборка

`BUILD_PORTABLE.cmd` создаёт portable-сборку в `dist\AURA`.

`BUILD_INSTALLER.cmd` создаёт установщик `AURA-Setup-0.6.1.exe`. Для локальной сборки установщика нужен Inno Setup 6.

GitHub Actions автоматически собирает установщик при публикации нового тега вида `v0.6.1`.

## Журналы

Журнал приложения:

`%APPDATA%\AURA\aura.log`

Журнал обновляющего модуля:

`%LOCALAPPDATA%\AURA\updater.log`
