# AURA 0.4.0

Голосовой ассистент для Windows с минималистичным интерфейсом и визуальными сценариями. Внешний вид основной версии сохранён.

## Обычный запуск исходников

1. Установите 64-битный Python 3.10 или новее.
2. Полностью распакуйте проект.
3. Запустите `START_AURA.cmd`.
4. При первом запуске дождитесь установки компонентов.

Если окружение было повреждено, используйте `RESET_AND_START.cmd`.

## Готовый установщик

`BUILD_INSTALLER.cmd` создаёт:

`dist\installer\AURA-Setup-0.4.0.exe`

Для сборки нужны:

- Python;
- Inno Setup 6.

Программа устанавливается в профиль текущего пользователя, поэтому обычные обновления не требуют прав администратора. Команды хранятся отдельно в `%APPDATA%\AURA` и не удаляются при обновлении.

## Автоматические обновления

AURA умеет:

- автоматически проверять GitHub Releases;
- скачивать установщик в фоне;
- проверять его SHA-256;
- предлагать установку;
- закрываться, обновляться и запускаться снова;
- сохранять пользовательские команды и настройки.

Настройка описана в `AUTO_UPDATE_SETUP.md`.

## Создание новой версии

После первоначальной настройки достаточно создать и отправить новый тег:

```bash
git tag v0.4.1
git push origin v0.4.1
```

GitHub Actions соберёт установщик, создаст файл SHA-256 и опубликует Release. Установленные копии AURA обнаружат его автоматически.

Локальная публикация без GitHub Actions:

1. Установите GitHub CLI и выполните `gh auth login`.
2. Запустите `PUBLISH_RELEASE.cmd`.

## Горячие клавиши

- `Ctrl + Shift + Space`: начать распознавание речи;
- `Ctrl + Shift + F12`: аварийно остановить выполняемый сценарий.

## Хранение данных

- команды: `%APPDATA%\AURA\commands.json`;
- журнал программы: `%APPDATA%\AURA\aura.log`;
- журнал обновления: `%LOCALAPPDATA%\AURA\updater.log`;
- журнал установки обновления: `%LOCALAPPDATA%\AURA\setup-update.log`.

## Безопасность обновлений

AURA устанавливает обновление только при совпадении SHA-256 установщика с отдельным файлом контрольной суммы в GitHub Release. Для публичного распространения также рекомендуется подписывать установщик сертификатом подписи кода.
