# AURA 0.7.3

Голосовой ассистент для Windows с локальной фразой активации, визуальным конструктором команд и автоматическими обновлениями.

## Главное в версии 0.7.3

- новая многослойная анимация сферы с объёмным ядром и ореолом;
- реакция на громкость микрофона;
- отдельные визуальные импульсы для активации, успеха, ошибки и шагов сценария;
- вращающиеся индикаторы распознавания и выполнения;
- настройки интенсивности анимации и режим уменьшенного движения;
- мастер первого запуска из пяти шагов;
- выбор микрофона и проверка уровня сигнала;
- отдельный центр настроек в прежнем стиле AURA;
- изменение фразы активации;
- включение и отключение голосовых ответов;
- автозапуск вместе с Windows;
- стабильный и тестовый каналы обновлений;
- резервное копирование команд и настроек;
- восстановление резервной копии;
- встроенная диагностика микрофона, модели активации, голосового пакета, горячих клавиш, обновлений и файла команд;
- исправлен ручной режим «Начать говорить»: тишина и неразборчивая речь больше не вызывают ответ «Я не нашёл такую команду».

## Анимация сферы

Сфера меняет состояние вместе с ассистентом:

- в ожидании медленно дышит;
- после фразы активации создаёт световую волну;
- во время речи реагирует на уровень микрофона;
- при распознавании и выполнении показывает вращающиеся точки;
- после успеха даёт зелёный импульс;
- при ошибке даёт короткий красный импульс и мягкое покачивание.

В настройках доступны низкая, обычная и высокая интенсивность, отключение реакции на микрофон и режим уменьшенного движения.

## Первый запуск

После установки AURA предложит:

1. Выбрать микрофон.
2. Проверить уровень голоса.
3. Настроить фразу активации и голосовые ответы.
4. Выбрать автозапуск.
5. Выбрать канал обновлений.

У пользователей, которые обновляются со старой версии, мастер автоматически не открывается. Его настройки доступны через кнопку с шестерёнкой.

## Запуск из исходников

1. Распакуйте проект в обычную папку, например `C:\AURA`.
2. Запустите `START_AURA.cmd`.
3. При первом запуске дождитесь установки компонентов.
4. При повреждённом окружении используйте `RESET_AND_START.cmd`.

## Голосовое управление

- активационная фраза по умолчанию: «Аура»;
- горячая клавиша ручного распознавания: `Ctrl + Shift + Space`;
- аварийная остановка сценария и записи: `Ctrl + Shift + F12`;
- фраза активации обрабатывается локально через Vosk;
- распознавание самой команды использует Google Speech Recognition и требует интернет.

## Настройки и диагностика

В центре настроек можно выбрать микрофон, проверить его сигнал, изменить фразу активации, отключить голосовые ответы, включить автозапуск и выбрать канал обновлений.

Кнопка «Проверить AURA» создаёт отчёт по основным компонентам. Резервные копии сохраняются в `%APPDATA%\AURA\backups`.

## Обновления

- первая автоматическая проверка выполняется вскоре после запуска;
- повторная проверка выполняется каждые 15 минут;
- стабильный канал получает обычные Releases;
- тестовый канал также может получать GitHub pre-release;
- обновление проверяется по SHA-256 перед запуском установщика.

## Хранение данных

Пользовательские данные находятся отдельно от программы:

- `%APPDATA%\AURA\commands.json`;
- `%APPDATA%\AURA\settings.json`;
- `%APPDATA%\AURA\aura.log`;
- `%APPDATA%\AURA\backups`.

Обновление программы не удаляет команды и настройки.

## Сборка

- `BUILD_PORTABLE.cmd` создаёт portable-сборку в `dist\AURA`;
- `BUILD_INSTALLER.cmd` создаёт `AURA-Setup-0.7.3.exe`;
- для установщика нужен Inno Setup 6;
- GitHub Actions автоматически собирает установщик при публикации тега вида `v0.7.3`.

## Безопасность

Системные команды требуют подтверждения. Не импортируйте сценарии из неизвестных источников и не сохраняйте в них пароли.
