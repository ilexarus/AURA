# AURA 0.8.3

Голосовой ассистент для Windows с локальной фразой активации, визуальным конструктором сценариев, режимами компьютера и автоматическими обновлениями.

## Главное в версии 0.8.3

- полностью удалена функция «Избранное»;
- убран переключатель из редактора команд;
- убран блок избранных режимов с главного экрана;
- новые команды больше не сохраняют поле `favorite`;
- старые `commands.json` с полем `favorite` открываются без ошибок;
- освободившееся место отдано истории действий;
- сохранены режимы, автоматический запуск, расписание и шаблоны.

## Запуск из исходников

1. Распакуйте проект, например в `C:\AURA`.
2. Запустите `START_AURA.cmd`.
3. При повреждённом окружении используйте `RESET_AND_START.cmd`.

## Управление

- фраза активации по умолчанию: «Аура»;
- ручное распознавание: `Ctrl + Shift + Space`;
- аварийная остановка сценария: `Ctrl + Shift + F12`;
- команды и режимы создаются через визуальный редактор.

## Автоматизации

Сценарий может запускаться по голосовой фразе, при старте AURA или ежедневно в заданное время. Доступны безопасные условия, переменные, запись действий и проверка сценария.

## Обновления

AURA проверяет GitHub Releases после запуска и затем каждые 15 минут. Перед установкой проверяется SHA-256.

## Данные пользователя

Команды и настройки хранятся отдельно от программы в `%APPDATA%\AURA`, поэтому сохраняются при обновлении.

## Сборка

- `BUILD_PORTABLE.cmd` создаёт portable-сборку;
- `BUILD_INSTALLER.cmd` создаёт установщик;
- GitHub Actions собирает Release при публикации тега вида `v0.8.3`.
