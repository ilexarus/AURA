# AURA 0.4.0

- Сохранён прежний интерфейс и анимация голосовой сферы.
- Добавлен отдельный установщик для текущего пользователя.
- Добавлена автоматическая проверка GitHub Releases.
- Добавлено фоновое скачивание обновления.
- Добавлена обязательная проверка SHA-256.
- Добавлен отдельный `AURAUpdater.exe`, который устанавливает новую версию после закрытия программы.
- Добавлен диалог установки обновления в прежнем стиле AURA.
- Добавлена проверка обновлений через меню системного трея.
- Добавлена автоматическая сборка и публикация выпусков через GitHub Actions.
- Добавлены `CONFIGURE_UPDATES.cmd` и `PUBLISH_RELEASE.cmd`.
- Пользовательские команды продолжают храниться отдельно от программы.
- Добавлена аварийная остановка сценария через `Ctrl + Shift + F12`.
- Добавлены действия управления мышью и окнами в конструктор команд.
- Добавлены тесты механизма обновлений и контрольных сумм.
